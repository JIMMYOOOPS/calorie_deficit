## Calorie Deficit

Allowing users to track their daily calorie intake and maintain a calorie deficit for weight loss.
This project is built using Go and PostgreSQL, with Docker for containerization. It includes a modular architecture for easy expansion and maintenance.

## Features

- **Daily Intake Tracking**: Users log their daily calorie intake via AI integration.
- **MCP Client**: The APP follows the MCP (Model Context Protocol) Client pattern, allowing for flexible AI model integration.
- **:warning:TODO: User**: The application supports user management, allowing users to create accounts and manage their profiles.
- **:warning:TODO: Calorie Deficit Calculation**: The application calculates the calorie deficit based on user input.
- **:warning:TODO: Front-End User Interface**: The application integrates with AI providers like OpenRouter and OpenAI for enhanced functionality.

## Architecture Overview

This application interacts with several external providers to deliver its features:

- **AI Providers (OpenRouter, OpenAI, etc.):**
  - The app integrates with AI services via the MCP Client pattern.
- **Database (PostgreSQL):**
  - All user and intake data is stored in a PostgreSQL database.
  - The database is managed via Docker Compose for easy setup and teardown.
- **Containerization (Docker):**
  - The app and its dependencies (like PostgreSQL) are containerized for consistent development and deployment.

## Initial Setup

### Environment Variables

- Create a `.env` file in the root directory according to the `.env.example` file.

### POSTGRESQL using Docker Compose

- `docker-compose -f docker/docker-compose.yml up`: This command will start a PostgreSQL database in a Docker container.

### OPEN_ROUTER_AI API KEY

- Obtain an API key from OpenRouter and set it in the `.env` file as `OPEN_ROUTER_AI_API_KEY`.

### Swagger Documentation

- Generate Swagger documentation using the `swag` command:

```bash
swag init
```
